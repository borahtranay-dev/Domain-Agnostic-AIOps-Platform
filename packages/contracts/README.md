- `Pipeline`, `PipelineRun`

## Rules
- Shared contracts must be agreed across all four leads before implementation.
- No member or AI assistant may unilaterally redefine shared contracts.
- E-commerce concepts must NOT be placed in this domain-agnostic core directory.
